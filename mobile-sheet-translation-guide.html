携帯アプリからシート翻訳を実行する手順書

パソコンで進めているGoogleスプレッドシート翻訳作業を、携帯のCodexアプリへ引き継ぎ、外出先から続きの作業を進めるための運用記事です。

作成日: 2026/06/11
対象: 任意の翻訳用シート
参照スキル: ebay-translation
目的: 携帯から迷わず安全に翻訳作業を引き継ぐ
全体像 PCから携帯へ引き継ぐ 携帯での実行手順 初期設定 送信文テンプレ AIに渡す手順書 スキル本文の要点 確認リスト

全体像

携帯からの操作は、基本的に「AIにチェックボックス列を作ってもらう」→「翻訳したい行にチェックを入れる」→「Codexアプリへ依頼文を送る」→「Codexが翻訳スキルに従ってeBay用データを書き込む」という流れです。

ポイント: シート名は固定ではありません。自分の運用に合わせて、任意のシート名をAIへ伝えれば使えます。この記事では例として 翻訳元シート、eBay出品用シート、タグ参照シート と書きます。
重要: eBay出品データは売上とアカウント安全に直結します。翻訳は「1行ずつ商品として精査」が最優先です。複数行を雑にまとめて判断しない運用にしてください。

PC作業を携帯Codexアプリへ引き継ぐ

Codexはパソコンだけでなく、携帯アプリからも同じように依頼できます。パソコンで作っている翻訳ルール、シート設定、作業の続きは、携帯のCodexアプリに「この作業を引き継ぎたい」と伝えることで、外出先から続けられます。

伝えたいこと: 家ではパソコンで準備や確認を行い、外では携帯からチェック済み行の翻訳を依頼できます。外出先でも、Googleスプレッドシートアプリでチェックを入れ、Codexアプリに実行依頼を送れば作業を進められます。

携帯Codexへ最初に送る引き継ぎ文

パソコンで進めているeBay用スプレッドシート翻訳作業を、携帯のCodexアプリで引き継ぎたいです。
この手順書に従って、チェック済みの商品行を翻訳し、eBay出品用シートへ書き込んでください。
作業前に、使用するシート名、読込元、書込先、タグ参照シート、チェック列を確認してください。

携帯アプリでの実行手順

1

AIにチェックボックス列を作ってもらう

初回だけ、AIに「翻訳対象を選ぶためのチェックボックス列」を作ってもらいます。基本はA列をチェック列にします。

このスプレッドシートで、翻訳対象を選ぶためのチェックボックス列を作ってください。
翻訳元シートのA列をチェック列にして、3行目以降の商品行にチェックボックスを入れてください。
A列の見出しは「翻訳対象」にしてください。
2

Googleスプレッドシートを開く

携帯のGoogleスプレッドシートアプリで対象シートを開きます。シート名は任意です。自分の運用で使っている翻訳元シートを開いてください。

3

翻訳したい行のA列にチェックを入れる

対象商品の行だけ、A列のチェックボックスをオンにします。チェック済み行は連続範囲として扱うため、できるだけ途中に空き行を作らないでください。

4

Codexアプリで依頼文を送る

Codexに スプレッドシート翻訳 と送ります。Codexが「どのシートで実行しますか？」と聞いたら、自分が使っている任意のシート名やプロファイル名を返信します。

5

完了後に書込先シートを確認する

書込先のeBay出品用シートを開き、タイトル、説明、カテゴリID、タグ、Item Specificsが入っているか確認します。

初期設定でAIに伝える内容

個人用のシート名やURLは記事に固定で書かず、使う人が自分のシート名に置き換えてAIへ伝えます。

項目 例 説明
読込元 翻訳元シート 日本語の商品情報が入っているシートです。
書込先 eBay出品用シート 英語タイトル、説明、カテゴリID、Item Specificsを書き込むシートです。
タグ参照 タグ参照シート 使用できる配送タグや分類タグを管理するシートです。
チェック列 A列 翻訳対象の商品だけチェックする列です。
担当者名 Codex 書込先シートの担当者欄に入れる名前です。
doGet URL GAS WebアプリURL 画像取得に使います。わからない場合は、AIに既存設定を確認してもらいます。
AIに初期設定を依頼する文面 
このスプレッドシートを、携帯CodexアプリからeBay翻訳できるように設定してください。

やってほしいこと:
1. 翻訳元シートのA列にチェックボックス列を作る
2. A列の見出しを「翻訳対象」にする

doGet URLは画像取得に使う内部設定です。通常、携帯から毎回手入力する必要はありません。

AIに渡す手順書

以下を携帯Codexアプリや別のAIに渡すと、作業の前提を共有できます。個人用のシート名は、実際に使う名前へ置き換えてください。

あなたはeBay出品用のスプレッドシート翻訳を担当します。

目的:
日本語の商品データを、eBay用の英語タイトル、説明、カテゴリID、タグ、Item Specificsに変換し、書込先シートへ追記してください。

最初に確認すること:
1. 使用するスプレッドシート
2. 読込元シート名
3. 書込先シート名
4. タグ参照シート名
5. 画像取得用doGet URL
6. チェック列
7. 担当者名

初期設定:
読込元シートのA列に、翻訳対象を選ぶチェックボックス列を作ってください。
A列の見出しは「翻訳対象」にしてください。
3行目以降の商品行にチェックボックスを入れてください。

実行条件:
チェック済み行だけを翻訳対象にしてください。
チェック済み行は連続範囲として扱ってください。
書込先シートの既存行は上書きせず、仕入れ先コード列が空の最初の行から追記してください。

品質ルール:
1商品ずつ、商品として精査してください。
元データが新品・未使用でも、eBay用には中古品または保管品として扱ってください。
Title / Description / Item Specificsに New / Brand New を使わないでください。
Descriptionは480字以内、英語、1行にしてください。
配送、梱包、値下げ、返品、出品者都合の説明は入れないでください。
タグは許可リストから0個または1個だけ選んでください。
カテゴリIDは空欄のままにしないでください。
書込後は必ず読み戻して、列ずれ、タイトル文字数、タグ、カテゴリID、Item Specificsを確認してください。

停止条件:
画像と商品行が一致しない場合、同じエラーが続く場合、カテゴリIDが大量に空欄の場合、eBay禁止語や危険素材ワードが見える場合は、作業を止めて報告してください。

ebay-translation スキル本文の要点

この手順は、ローカルの ebay-translation スキルに基づいています。携帯からの依頼でも、実際の翻訳品質はこのスキル本文のルールに従います。

1行ずつ精査 中古品前提 画像はdoGet優先 タグは0個または1個 カテゴリID必須確認 書込後QA必須

第一ルール: 情報精査は1行ずつ 
これは商品です。データ行ではありません。1件1件が実際に販売される商品です。

情報精査（ソーステキスト読込・画像確認・タグ判定・カテゴリ判定・Title/Description/Item Specifics生成）は必ず1行ずつ実行する。

バッチ処理で複数行を一度に判定してはならない。
携帯運用で特に重要なルール 
・元データが「新品」「未使用」「未開封」でも、eBay出品では基本的に中古品 / used-stored collectible 扱いにする。
・Title / Description / Item Specificsで New / Brand New は使わない。
・Descriptionは480字以内、ASCII、1行のみ。
・配送方法、梱包条件、値下げ、返品、出品者都合の説明は入れない。
・タグはタグ参照シートA列の許可リストから0個または1個だけ。
・categoryIdが空欄のまま残る場合は、完了前に必ず補完を試みる。
・書込後に必ず読み戻して、列ずれ、タイトル文字数、タグ、カテゴリID、Item Specificsを確認する。
画像取得ルールの抜粋 
商品画像はユーザーのGAS Webアプリ（doGet）からbase64で取得する。

safeImagesがあれば、それだけをvisionに渡す。
safeImagesが空の行だけmercariUrlsを使う。

doGet URLが指示文またはプロファイルに無ければエラーで停止する。
=IMAGEのメルカリURLに勝手に落とさない。
書込位置ルールの抜粋 
対象行範囲はソースシートの行範囲のみを指す。
書込先シートには H列（仕入れ先コード列）が空の最初の行を毎バッチ再取得して特定し、その行から順次書き込む。
絶対に書込先シートの既存データを上書きしない。

実行前後の確認リスト

実行前

  • 翻訳したい商品のA列だけチェックされている。
  • チェック行ができるだけ連続している。
  • 日本語タイトル、説明、価格、URL、画像が元シートに入っている。
  • 今回使うシート名、読込元、書込先を間違えていない。

実行後

  • 書込先のeBay出品用シートに新しい行が追加されている。
  • M列の英語タイトルが80文字以内で、商品内容に合っている。
  • N列の説明に配送・梱包・値下げ・返品などの不要文が入っていない。
  • D列タグが1つ以内、F列カテゴリIDが空欄ではない。
  • P列以降のItem Specificsが商品に合っている。
  • 元データが新品でも、eBay側で New / Brand New と書かれていない。
停止すべき状態: 画像の商品と行の商品が違う、カテゴリIDが大量に空欄、タイトルに根拠のないRare/Limitedが入る、同じエラーが続く、eBay禁止語や危険素材ワードが見える場合は、追加作業を止めて確認してください。
